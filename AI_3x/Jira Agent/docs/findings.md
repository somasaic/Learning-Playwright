# Findings — Research & Discoveries

## Jira Cloud API

- **Endpoint**: `GET /rest/api/3/issue/{issueKey}` — returns full issue with ADF description
- **Auth**: Basic Auth as `base64(email:apiToken)` in `Authorization` header
- **ADF (Atlassian Document Format)**: Rich text descriptions are returned as a nested JSON tree, not plain text. Must be recursively flattened before feeding to LLM.
- **Rate limit**: Jira Cloud has a generous rate limit for individual user tokens; no throttling needed for this use case.
- **CORS**: Jira Cloud blocks browser-direct requests — requires server-side proxy (hence `server.js` + `api/` routes).

## GROQ API

- **Base URL**: `https://api.groq.com/openai/v1/chat/completions`
- **Model**: `openai/gpt-oss-120b` (free tier, OpenAI-compatible)
- **JSON Mode**: Supported via `response_format: { type: 'json_object' }` — requires at least one mention of "JSON" in the system or user prompt.
- **Gotcha**: Even with json_object mode active, some responses may be wrapped in ```json``` markdown fences. Added fence-stripping before `JSON.parse()`.
- **Token limit**: ~120k context window. Jira descriptions are typically well within this limit.
- **Hallucination mitigation**: Prompt explicitly instructs model to use "TBD" for missing fields; schema hint is embedded in user message.

## Architecture Decisions

- **Monorepo (single package)**: Both tools (Test Plan + Test Strategy) share the same Express server, Vercel API, and React app. Simpler than separate deployments; tools are distinguished by endpoint and tab.
- **Deterministic Markdown rendering**: LLM produces JSON only; all Markdown is generated by `renderMarkdown()` functions in `tools/`. This ensures consistent formatting regardless of model output variation.
- **LocalStorage for config**: Jira credentials stored in browser localStorage so users don't re-enter them. Falls back to server `.env` if blank.

## Constraints

- Jira API token must be a **classic API token** from id.atlassian.com, not OAuth.
- GROQ free tier has rate limits (approx. 30 req/min on free plan). No queue needed for single-user use.
